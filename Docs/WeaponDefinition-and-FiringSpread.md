## 参数作用

| 中文分组 | 内容与用途 |
|---|---|
| 基础 | 武器展示名，影响已有界面显示 |
| 开火 | 默认和允许模式；射击间隔是秒，越大射速越慢；连发间隔/恢复间隔控制Burst |
| 弹药 | 弹匣容量、初始装弹、初始备弹；初始值只给新生成武器，当前剩余弹药仍保存在实例 |
| 伤害与弹道参数 | 每发伤害、现有穿甲值、爆头倍率、最大射程（厘米），展开编辑 |
| 散布 | 静止、移动、跳跃、慢走基础精度，角度越大越不准确；移动阈值决定何时使用静止精度 |
| 连续射击散布 | 只针对连续成功开火额外增加的随机误差，保持首发基础精度 |
| 后坐参数 | 展开调整固定序列、镜头反馈、施加平滑和恢复；序列X为上抬、Y为左右角度 |
| 换弹 | 是否锁定装填量、逐颗装入、满数量空仓一次装入，保留现有换弹流程 |

## R08 / Viper 连续射击散布首版

| 参数 | 已迁移初值 | 含义 |
|---|---|---|
| 启用连续射击散布 | 开启 | 其他三枪关闭，保持已有行为 |
| 静止散布角度 | 0 | 站定、散布恢复完后第一枪保留精准 |
| 每发增加散布 | 0.15度 | 本发成功之后增加，影响下一枪 |
| 连续射击散布上限 | 0.8度 | 额外散布最多到这里，不无限扩大 |
| 连续射击散布恢复延迟 | max(该枪射击间隔+0.05秒,0.35秒) | R08实际射击间隔0.3，所以为0.35秒；Viper从它实际射速派生 |
| 连续射击散布恢复速度 | 2度/秒 | 延迟后逐渐收回，最大散布再需0.4秒收完 |
| 后坐序列停火重置时间 | 0秒 | 每枪清掉前发方向偏移，不再像步枪持续爬升 |

单发镜头与枪身动作保留。移动/空中基础散布依旧生效；首发精准的判断应在站定情况下进行。固定序列首项使用旧资产实际数值，空数组才补单发值；所有力度仍需玩家观感确认。

## 集中试玩

1. R08站定先打一枪，再快速点射一匣：第一枪准确，后续逐渐散开，整体不按发数持续向上爬。
2. 停约1秒重新瞄准打一枪：恢复首发精度。Viper做同样检查。
3. AK、TR15、SRM各打一小段：应保持迁移前接受的效果。
4. 任一武器打掉几发后切枪/丢弃重拾；已有检查点恢复时剩余弹药不应补满。只集中反馈出现异常的项。
