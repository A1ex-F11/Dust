# 准星样式数据资产（2026-10-17）

本批为已收尾W08的附加配置与复用工作，保留已认可手感。W12的玩家菜单/保存与命中击杀反馈仅登记，尚未实现。

## Dust2 当前入口

默认样式资产：`/Game/Code/UI/DA_准星样式_默认`。已绑定既有`WBP_Crosshair`，无需重新接初始化蓝图。保存前按控件CDO读取旧外观，因此默认仍为长度7、粗细1.75、中心间距(3,3)、白色/透明度1、动态扩散开、样式显示强度1；现有组件射击反馈倍率/跟随/切枪时序不改。

资产内可改：中心间距、线条长度、线条粗细、颜色与透明度、启用动态扩散、扩散显示强度。关闭动态只固定显示，枪械真实散布仍由武器计算。

要新建样式，可复制默认资产后改名，或“杂项→数据资产”选择“准星样式预设”。在WBP_Crosshair类默认值的StyleAsset选择它。旧外观字段仅在未指定样式时作为兼容回退。

## 运行时接口

控件`ApplyStyleOverride`只修改当前实例，`ClearStyleOverride`恢复资产；`SetStyleAsset`选择默认资产。`ResolveStyleTargetGap`在过渡前计算样式目标，随后才走原平滑状态并`SetCrosshairGap`，不重复放大。菜单/保存和命中临时反馈留待W12，不写共享资产。

## 可复用仓库

已核`A1ex-F11/UEWeaponKit`是独立UE5.8插件仓库。本轮同步的是枪械配置类/结构/接口与必要运行接入、通用准星/样式/过渡数学和相关测试。J已明确不上传五枪具体数值、JSON或.uasset。本地导出仅作证据，不进入发布；不制作数值导入包。

Dust2接入组件依赖本项目的玩家、库存和表现，留在Dust2。插件中的控件与样式只依赖引擎，宿主提供总散布投影和生命周期显隐。插件的类型保留WeaponKit前缀，可与Dust2同时存在。
