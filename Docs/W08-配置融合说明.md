# W08 枪械配置融合（2026-10-17）

J确认：初始装弹数与弹匣容量不合并，其余按审查方案实施。本批范围是统一作者配置、共享预设及五枪迁移，保持固定轨迹、弹药、伤害、射速和恢复状态的既有职责。不启动W09，不写交接或跨聊天通知。

## 现在如何编辑

- 基础与开火：只编辑“开火模式（首项为初始）”。列表按顺序循环；存档中的有效当前模式仍优先。原默认模式按环序旋转迁入首项。
- 弹药与装填：使用一个“装填方式”选择整弹匣、逐颗、逐颗但全空且备弹充足时整批。数量锁定仍是独立高级项。“初始装弹数”“弹匣容量”保留原字段与数值。
- 精度：腰射常调基础散布、最大射击额外散布、连续到顶参考发数、满累计恢复秒数。姿态精度通过预设引用；要本枪特殊化时启用覆盖，修改独立姿态参数。独立瞄准关闭则继承腰射，打开后同样配置四项及姿态预设。旧新算法切换、旧兼容精度表不再是编辑入口。
- 后坐与镜头：保留固定序列、横纵倍率、瞄准倍率、恢复和每枪镜头反馈强度。镜头回落/平滑/立即比例在镜头预设里；特殊枪启用独立镜头参数。当前五枪已核固定且独立模式，随机和旧控制器参数退出作者面板，底层兼容仍保留。

## 迁移取舍

五份Definition和旧源码改前原字节备份在before目录。旧字段保留序列化及蓝图读取兼容，不继续作为可编辑权威；本批没有物理删除兼容字段，以免旧蓝图、尚未迁移资产或回退断链。

姿态：旧绝对角转换为 max(0, 旧姿态角-基础角)，新配置为基础+水平惩罚+空中惩罚+射击累计。旧值低于基础时不会产生负惩罚。旧值已使用新叠加模式的配置原值保留。瞄准基础精度仍沿保存资产，不套用腰射建议表。

射击：旧“每发/上限/恢复延迟/速度”无法被整数参考发数和无延迟恢复完全等价表达。迁移的四项显示为参考值，同时内部保留原射击节奏；修改本组四项任意一项后，使用新的直观计算并取消旧延迟。只改姿态预设不会改变射击增长/恢复。新创建和已使用直观精度的配置不需要这份过渡数据。

共享：只合并数值相同的现有设置，不把不同枪强行套成一组。共用预设在 /Game/Code/ConfigurationPresets。编辑预设会影响引用它的枪；独立覆盖只影响当前枪。预设名中的标识用于按值去重，不按枪名写运行分支。
