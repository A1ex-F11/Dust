# Dust2 — UE 5.8 单人科幻战术 FPS Demo（C++ 源码仓库）

> **仓库说明**：GitHub 仓库名为 `Dust`，Unreal 模块名为 `Dust2`。本仓库为 **UE 5.8 C++ 源码与脱敏配置快照**，不包含 `Content/` 目录、第三方插件、模型/动画/蓝图资产（环境素材使用 Fab 的 *Modular SciFi Season 1 Starter Bundle*）及打包产物，因此无法直接克隆编译为完整可运行游戏。Windows 独立开发包已完成全流程实机验证，实机演示视频成片制作中。

## 项目简介

- **引擎版本**：Unreal Engine 5.8
- **项目类型**：3D 第一人称射击（单人、任务驱动单关卡 `L_SciFiDemo`）
- **开发周期**：2026 年 9 月初 – 至今（约 2.5 个月）
- **核心流程**：补给 → 多区域交火清场开门 → B 点检查点存档 → 回防拆除 C4（单局闭环）
- **技术边界**：单机无联机、未使用 GAS；强调 C++ 与蓝图的清晰职责分离。

## 个人职责与 AI 协作说明

本项目为 **个人主导 + AI 协作** 完成的求职向工程 Demo：
- **个人独立负责**：核心玩法设计与系统取舍、C++/蓝图架构边界规划、关卡搭建（`L_SciFiDemo`）与蓝图接线、Enhanced Input / UMG / 武器与动画资产配置、全部编译运行验证、Crash 调试、性能剖析优化与 Windows 独立包打包回归。
- **AI 协作（Codex）**：在个人设计约束与接口规范下，协作完成部分 C++ 核心逻辑实现与 Code Review。

## 架构与核心模块

项目采用 **C++ / Blueprint 混合架构**：C++ 持有权威运行时状态、稳定规则与受控 API；蓝图负责输入接线、关卡编排、HUD 表现、动画蓝图与参数调优。

1. **武器运行时与可复用插件（`AWeaponRuntime` / `UEWeaponKit`）**
   - 设计 `TryCommitFire` 统一射速与弹药门禁，支持半自动、全自动、三连发共 5 把武器（含 R08 左轮逐发装填）。
   - 构建换弹状态机，通过 `ReloadReady` 动画通知提交弹药并放行开火；切枪时主动打断换弹并缓存旧枪引用，防止异步回调竞态。
   - 已将核心武器系统抽离为独立插件 `UEWeaponKit`，并在独立宿主工程中通过编译与测试验证。

2. **纯数据检查点系统（`FCheckpointData`）**
   - 检查点仅序列化纯数据（生命值、双槽武器类/弹药/射击模式、任务阶段、已阵亡敌人 ID），**不保存任何 Actor 引用**。
   - 关卡重载后按纯数据重建运行时实例，规避跨关卡野指针与生命周期残留问题，支持死亡重试完整恢复战斗状态。

3. **敌人 AI 战斗系统（`AIPerception` + `StateTree`）**
   - 基于视觉与听觉感知驱动 `StateTree` 战术状态机，支持 8 名敌人同场交战。
   - 实现索敌交火、目标丢失后前往最后目击点搜索、边移动边射击及近距友军避让等行为。

4. **五阶段任务状态机与终局互斥门禁**
   - 实现“补给 → B 点推进 → 回防 → C4 已安装”五阶段单向门禁，通过动态多播委托解耦驱动 HUD 更新。
   - C4 攻防采用 **40 秒倒计时 / 8 秒拆除** 规则，并设置“第一个结果获胜”的终局互斥门禁，防止胜负状态并发冲突。

## 性能剖析、排错与自动化测试

- **Unreal Insights 性能调优**：针对 8 敌人同场交战场景，结合 `Unreal Insights` 与 `dumpticks` / `listtimers` 按“存活 / 尸体留场 / 尸体清理”三阶段定位开销，落地死亡后停用隐藏躯体 Tick、关闭拾取物骨骼 Tick、同次 AI 决策视线 Trace 去重及敌人武器后坐休眠策略；游戏模式实测约 69–76 FPS（优化后实测观察约提升 10 FPS），并完成全流程玩法回归验证。
- **典型问题排查**：
  - 使用 Crash Reporter 调用栈定位并修复 `TryCommitFire` 误递归导致的栈溢出崩溃。
  - 修复删减动画采样后旧缓存导致的打包启动约 43 秒闪退问题，通过引擎原生 `ResampleData()` 重建保存解决。
- **自动化验证**：基于 UE Automation Test 编写回归用例，涵盖 6 条伤害规则合同测试及武器/瞄准等切片回归（46/46、51 项等多组用例通过）。

## 仓库目录结构

- `Source/`：游戏模块、数据结构、组件及自动化测试源码。
- `Config/`：脱敏后的工程默认配置（已移除本机 `AdditionalPluginDirectories` 绝对路径与 Android 文件服务 `SecurityToken`）。
- `Docs/`：含 `验证与更新记录.md`，记录各阶段改动与实际验证范围。
- `Dust2.uproject`：工程描述文件（引擎关联标记 `5.8`）。
