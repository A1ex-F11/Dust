# Dust / Dust2 C++ 源码

本仓库保存 Dust2 UE5 学习工程的 C++ 源码、工程配置与同步说明。GitHub 仓库名为 Dust，Unreal 模块名仍为 Dust2。

## 当前范围

- `Source/`：游戏模块、数据结构、组件及现有源码测试。
- `Config/`：工程默认配置，不含个人编辑器偏好。
- `Dust2.uproject`：工程描述；发布副本移除了本机 `AdditionalPluginDirectories` 绝对路径，原工程保持不变。
- 发布配置移除了 Android 文件服务的 `SecurityToken`，原工程保持不变；需要该服务时在本地重新配置。
- 不包含 `Content/`、第三方插件、模型、动画、蓝图资产、编译产物、缓存、日志或打包文件。

这是一份源码快照，不是下载后即可运行的完整游戏。默认地图、GameInstance、GameMode 等仍引用原工程 Content；查看源码或在具备原工程资产与依赖的环境中使用。引擎关联沿用原工程标记 `5.8`，不代表该环境已在其他机器验证。

## 首次快照与验证边界

2026-10-01 首次从用户指定 Dust2 工程读取文件。仓库建立与上传核验不等于重新通过 UE 编译、完整游戏运行或全部文件验收；最新编辑中的功能不得仅因为进入首次快照就被称为已验证版本。后续每次更新在 `Docs/验证与更新记录.md` 说明改动及实际验证范围。

## 分支和提交

- `main`：当前源码基线及后续已验证更新。
- 分支是从一个版本出发的另一条开发路线，例如 `feature/weapon-pickup`，用于隔离较大的功能试验。验证后才合回 main。
- 提交（commit）是一组改动的历史记录，不是另一份需要手动维护的文件夹。

## 后续同步

用户已授权：任务窗口汇报已验证代码更新时，同步相关源码和配置到本仓库，返回提交链接。普通讨论、未保存代码、仅静态截图或待运行验证的功能不自动记为已验证更新；无差异不创建空提交。同步前核对来源、差异和证据，不覆盖他人更新，不强制推送。

首次范围不含蓝图。仅蓝图发生变化时记录结果及源码未变化，不宣称蓝图已备份。上传蓝图或其他资产需另行明确范围。
